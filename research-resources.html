fuzzyml — Fuzzy Logic Modeling Library

A lightweight Python library for fuzzy logic modeling and soft computing

Python Open Source

fuzzyml is a lightweight, extensible Python library designed for fuzzy logic modeling, fuzzy set operations, and soft computing applications. It provides intuitive APIs for defining membership functions, fuzzy rules, and inference systems, making it suitable for researchers and practitioners working with uncertainty-aware systems.

Fuzzy Logic Soft Computing Python Membership Functions Inference Systems Rough Sets

aicore — Python Core AI Library

Core ML primitives, distance metrics, and foundational utilities for AI research

Python Open Source

aicore is a foundational Python library providing core machine learning primitives, distance metrics, similarity functions, and essential utilities for AI research. Designed as a lightweight dependency-free toolkit, it serves as the building block for more complex machine learning pipelines and research prototypes.

Breast Cancer CPTAC GDC 2025 — Classification Dataset

Clinical + gene expression data for binary classification of breast cancer stage

v1.0.1 CC BY 4.0

A curated binary classification dataset derived from the CPTAC GDC 2025 breast cancer study via cBioPortal. It combines clinical features (age, race, ethnicity, TMB) with the top 500 most informative gene expression features, selected by variance and correlation with cancer stage. Designed as a reproducible benchmark for stage prediction (Early vs Late).
